LIFTOS — MOCK 09-19

Review sheet, not the app. Family glyphs, the merged weight card, and the three set-row changes (rest clock, miss opens its note, steppers instead of the keypad). Real tokens and real CSS lifted from index.html, so what reads well here reads the same on the phone. Nothing is wired.

1 · Movement families — ten glyphs

Large is review size. The two dim copies are the sizes they actually ship at: 22px on a panel head, 12px if one ever needs to sit inline. Regex-mapped like ROLE_ICONS, so a new exercise name resolves without a code change and an unrecognised one falls to the last mark instead of a hole.

2 · Coverage — every Meso 3 movement, resolved

Order matters: row and pulldown are tested before the floor pulls, or "Plate-loaded pulldown" would land with "Clean pull"; the pulls are tested before the lifts, or "Snatch pull" would draw a snatch catch; jerk before clean, or "Clean & jerk" would draw a front rack. Nothing reaches the fallback.

3 · Train tab — glyph placement and the new set row

train · glyph inline before the title

what changed

Rest clock sits in the header as a pill, same family as the sync chip. It starts on a tick and resets on the next one, so it never moves and never pushes a panel around mid-session. Absent until the first tick of the day.

Steppers replace the keypad. Correction to what I said earlier: a blank field already writes the planned value, so a normal set was always one tap. The friction is only in deviating. ± 5 lb and ± 1 rep, and the number itself is still tappable to type an exact value. An adjusted field goes coral so the deviation is visible without reading the digits.

A miss opens its note, focused, amber, labelled with the set. Set 2 below is in that state. The note is the existing per-panel note field, so no new row and no schema change.

Haptics can't be mocked here. I'll wire it behind a capability check and report what your phone actually does.

4 · Weight tab — three cards become one

now · three cards, two seams, recent list

proposed · one card, write always visible

what changed

One card, one ring. The average, the chart and the range switch keep their order, a hairline replaces the card boundary, and the entry row sits below it, always visible. No toggle: the write is why you opened the tab.

Recent folds into the chart. Tap a dot and that weigh-in loads into the form, which is what the Recent list was for. The selected dot goes solid coral and a single line under the chart names it with a Delete. That removes an entire card and a scroll without losing edit or delete.

Cost: the last five weigh-ins are no longer readable as a list, you read them off the chart instead. Say if that's a loss and I'll keep Recent as a collapsed row inside the same card.
